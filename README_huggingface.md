# ATTRITION — one engine, many worlds

Bandits with consumable action sets: campaign persuasion against 543 real
Lok Sabha constituencies, clinical/AMR stewardship, agent-ecosystem tool
routing, cybersecurity patch prioritization, and fisheries harvest
decisions — one engine, real data, disclosed limitations throughout.

This Space runs the full interactive frontend (real interactive map,
Constituency Lab, Strategist, Forecast, and every other world) — the same
app as the project's [GitHub repo](https://github.com/NavikkumarModi/attrition),
built and served as a single container.

See the GitHub repo's [README](https://github.com/NavikkumarModi/attrition#readme)
and [FINDINGS.md](https://github.com/NavikkumarModi/attrition/blob/master/FINDINGS.md)
for the full research writeup, methodology, and every disclosed
limitation behind these numbers.
